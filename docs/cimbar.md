# 手机高速流水码

点击左上角“二维码工具”→“高速流水码 · Cimbar”。两部手机均安装此版本；发送手机选“创建”，选择文件或输入文本，再开始播放；接收手机选“扫描”，允许相机权限并开始扫描，完成后保存到手机。

- 内置官方 Cimbar v0.6.8 JS/WASM，离线运行。无需电脑、外部浏览器、账户或网络。
- Cimbar B / mode 68（1040×1040 原始画布），Wirehair + Reed–Solomon + zstd。它是彩色图块传输格式，不是 RFC 6330。本 App 在 Cimbar 传输内容中加入 CMBAPP01 封装（8 字节标识、4 字节大端原始长度、32 字节 SHA-256、512 字节随机填充、原文件），修复低熵小文件无法读出的问题并验证内容完整性。保存时移除封装；原文件字节和名称不变。建议两端使用本 App；外部 Cimbar 接收器会收到封装后的内容，本 App 可接收普通 Cimbar B 文件但没有本 App 的额外 SHA-256 校验。普通二维码和“黑白流水码 · 兼容旧版”的 500 字符上限不变。
- 发送默认 15 fps，可调 5–30 fps；实际帧率受手机图形性能和屏幕刷新率影响。播放期间屏幕常亮并提高亮度，暂停或离开恢复系统亮度。
- 文件发送上限 16 MiB，解压接收上限 32 MiB。收到的内容保留到重新识别/退出；取消保存可以重试。保存使用系统文档选择器。
- 接收使用后台 WASM Worker；每次最多一个相机帧在处理，过时的未处理相机图像直接跳过，避免积压旧帧。已经进入解码器的有效数据不丢弃。VideoFrame 的 NV12/I420 图像显式指定平面步长，其他格式转 RGBA，旧环境有 canvas 读取回退。
- 预览使用视频原始比例（object-fit: contain）。普通 QR 和旧 RaptorQ 摄像头的 vendored mobile_scanner 修复为 Preview 的实际尺寸与旋转信息，避免分析流与预览流尺寸不一致造成压扁。
- 暂停或切换创建/扫描保留接收解码状态；重新识别销毁并重建 Worker。退到后台停止相机和发送，恢复前台后由用户继续。

## 验证

`NODE_PATH=<含 Playwright 的 node_modules> node scripts/test_cimbar.cjs`

真实内置 WASM 将 256 KiB 随机内容编码成图像，再通过 VideoFrame → Worker → 图像识别 → 喷泉恢复 → 解压，丢弃 1/3 帧后逐字节比对。覆盖中文/emoji 文件名、空文件、1/500/16384/16385 字节边界、暂停、清空、横竖屏布局。此测试不包含屏幕拍摄的光学损失，耗时不等同于手机传输速度。

Cimbar 官方性能介绍：https://github.com/sz3/libcimbar/blob/v0.6.8/PERFORMANCE.md 。不将其显示器到手机的测速宣传为本 App 两部手机的保证速度。真实速度需在设备上根据距离、焦距、屏幕分辨率和帧率实测。
